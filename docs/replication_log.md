# Geopolitical Distance Replication Log

## Status
This repository now contains a full R pipeline scaffold for the UNGA ideal-point-distance replication in `R/geopolitical_distance/` only (including pipeline orchestration files).

## Data sources configured
- UNGA roll-call votes and metadata via the `unvotes` R package (`un_votes`, `un_roll_calls`, `un_roll_call_issues`).
- Optional bilateral trade shares via `data_raw/bilateral_trade_shares.csv`.

## Specifications implemented
- `baseline_all_2021`
- `all_2023`
- `economic_2021`
- `post1990_all_2021`

All are parameterized in `config/geopolitical_distance.yml`.

## Ambiguities and handling
- Economic-vote scope is ambiguous in the source language; implemented literal keyword-based filter on issue labels containing `econ`/`economic`.
- Normalization implemented exactly as yearly theta-range scaling.
- Published Bailey/Strezhnev/Voeten country-year dynamic estimates are not bundled here; the current estimator is a 1D ideal-point model (`pscl::ideal`) run by year as an informed approximation when full dynamic-country-year series are unavailable.

## Unresolved environment constraints in this run
- `Rscript` is not available in the execution environment, so the pipeline could not be executed end-to-end in this session.
- Because execution did not run, output CSVs and figures are generated by scripts but not materialized from a successful run in this environment.

## Validation hooks
- Validation checks are implemented in `R/geopolitical_distance/pipeline/validate_and_log.R` and write to `output/geopolitical_distance/validation_checks.csv`.
