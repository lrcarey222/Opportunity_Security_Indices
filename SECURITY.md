# Security Policy

## Reporting vulnerabilities

If you discover a security vulnerability, please report it privately to the project maintainers. Do not open a public issue for sensitive reports. If GitHub Security Advisories are enabled, you may use that channel.

Please include enough detail to reproduce the issue and any relevant impact assessment.

## Data and secrets

Do not commit credentials, tokens, or proprietary datasets to this repository. If you suspect sensitive data has been committed, notify maintainers immediately so it can be removed and rotated.
